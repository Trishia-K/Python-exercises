A collection of Python scripts and projects built 
during my classes as a computer science student at Uganda Christian University.

| File | What it does |
|---|---|
| `Simple calculator.py` | Basic arithmetic calculator with user input |
| `binary_search.py` | Binary search algorithm implementation |
| `binary_search_modified.py` | Modified binary search with extra logic |
| `linear_search.py` | Linear search implementation |
| `Sorting algorithms.py` | Sorting algorithm implementations |

| `GRAPH TRAVERSAL ALGORITHMS.py` | BFS and DFS graph traversal |
